# SQL 기본

## ORDER BY
- 어떤 순서로 정렬될지 정함
    1. 문자를 오름 / 내림 차순
    2. 숫자를 오름 / 내림 차순

```sql
select *
from users
Order by id ASC;
```
- ASC(ascending) : 오름차순, 생략해도 됨
- desc : 내림차순

- order by는 컬럼명을 몰라도 정렬을 수행하는게 가능하다<br>
몇번째 컬럼인지 숫자로 입력해도 가능

```sql
SELECT *
from users
Order BY 3 DESC;
-- 3번째 컬럼, 여기선 username을 기준으로 정렬했다.
```

```sql
SELECT username , phone , city, country, id
from users
ORDER BY 1;
-- 1번째 컬럼, 여기서도 username
```

- 만약 id가 기분으로 오름차순이 되길 바랐다면 틀린 코드다.<br>
select 절의 실행 결과를 기준으로 정렬하기 때문에 1번 컬럼이 username이 되었으니
username 기준으로 오름차순이 되었다.

- 물론 숫자로 지정하는 방식은 잘 쓰지 않는다.

- Order by 기준을 복수로 잡을수도 있다.<br>
`Order by 1번 컬럼 ASC/DESC, 2번 컬럼 ASC/DESC`<br>
과 같은 방식으로 작성할 수 있는데, 1번을 기준으로 정렬한다음 2번에서 재정렬을 수행한다.

```sql
SELECT city, id
from users
ORDER BY city desc , id;
```

- 위 코드는 내림차순으로 정렬한 같은 city 중에서 id를 오름차순으로 정렬한것과 같다.

### select / from / where / order by 실무 예시

- 배달 서비스에서 어떤 방식으로 적용하는가?
1. 2023-08-01에 주문한 내역중 쿠폰 할인이 적용된 내역만 추출하기

2. 마포구에서 1인분 배달이 가능한 배달 음식점만 추출하기
```sql
select *
from 음식점정보

```

- 전자책 서비스의 경우
1. 출간된 지 한 달 이내인 신간 중 페이지 수가 200이상인 도서만 추출

```sql
select *
from 도서정보
where 출판일자 > = (오늘일자 -1달) AND 페이지수 >= 200;
```

2. 최근 한 달 이내에 도서 구독 멤버십에 가입한 회원만 추출하기
```sql
select *
from 회원정보
where 가입일자 >= (오늘일자-1달) AND 멤버십가입여부 = 1
```

- 참조 사항 : 오늘 일자를 가져오는 부분과 특정 일자에서 한달 차감하는 함수가 DB별로 다를 수 있기 때문에 정형화해두지 않았습니다. 조직 별 DB 채용한 것을 기준으로 학습할 필요가 있다.

## 데이터를 계산하는 함수
- 합 / 평균 / 개수 세는 등의 집계 함수
- 문자열을 잘라내거나 / 대소문자 변경 들을 수행하는 일반함수
- 그룹별로 집계 함수를 적용하기 위해 데이터를 나누는 Group by

    - 전체 데이터에 함수를 적용하기도 하지만, 그룹별로 수치를 도출하는 일도 자주 있다. 그런 경우 group by를 이용해 데이터를 그룹으로 묶은 후 필요한 함수를 적용

```sql
SELECT count(id) as cnt 
from orderdetails;
```

- group by로 계산한 결과를 필터링 하는 HAVING
    - group by를 사용하면 국가별 회원수를 추출하는 것이 가능한데 , 그 중에서 마케팅 효율을 높이기 위해서 국가별 회원 수 추출하고, 그 중에서 회원 수가 10명 이상인 국가만 재추출하는 등 집계 함수로 계산한 결과 중에서 조건에 맞는 데이터 만 필터링 하는 경우도 존재
    - 그러면 일단 집계 함수가 적용된 이후에 where을 써야 한다. 결과값 필터링을 having으로

## 집계 함수 
1. count : row 개수 세는거
2. Avg : 평균
3. sum : 숫자형 데이터 값을 더할때

```sql
select count(*)
from users;
```

이상의 쿼리문은 회원 테이블의 row 개수를 추출한다.
`count(*)`는 대상 테이블에 있는 전체 행의 개수를 세는 역할을 한다.

```sql
select count(country)
from users;
```
참고로 위 결과값은 76, users의 수는 77이지만, country가 null값인곳이 하나 있다.<br>
count 함수는 컬럼값이 null이 아닌 행의 개수를 retrun한다.<br>
중복된 country도 세어버린 값이다.

- 중복 제거 명령어 `DISTINCT`

```sql
select count(distinct country) as countries
from users;
```

`nill은` 집계 함수 상에서 카운팅이 안되는거지 그냥 보여줄때는 나온다.

- Min() : 최저값 추출
- Max() : 최대값 추출<br>
둘다 문자열에 사용가능
```sql
SELECT MIN(price)
from products;

SELECT Max(price-discount_price)
from products;

SELECT sum(price)
from products;

SELECT round(AVG(price),2) AS avgPrice
FROM products;



```


- users에서 회원의 가입일자, 가입년월, 가입일시 만 출력하기
```sql
select substr(created_at,1,10) -- 1~10까지
from users;
```

- substr(p1,p2,p3)
    - p1 : 잘라낼 varcahr() 자료형
    - p2 : 시작 인덱스(1부터시작)
    - p3 : 출력되는 숫자(안쓰면 끝까지 추출)
    두개만 쓰면 잘라낼 varchar()와 시작인덱스만 선언됨
    - `주의` p2가 5, p3가 6이면 5부터 6까지 2글자가 출력되는게 아니라<br>
    5부터 시작해서 6글자가 출력된다.

```sql
SELECT SUBSTR(created_at,6,2) AS MONTH,SUBSTR(created_at,9,2) AS DAY ,  created_at
FROM users;
```

```sql
select Length(username) as len, username 
from users;
```

- Length() : len()와 같네요.<br>
문자열의 길이를 return하는 것이 동일하다. 그런데 DB 종류에 따라 LEN()으로 쓰는 것도 있다.

- upper() : 괄호안 varchar를 대문자로 변경
- lower() : 소문자로 변경

### 집계 함수 종류(중 일부)
1. sum
2. avg
3. max
4. min
5. count

### 일반 함수(중 일부)
1. round(p1,p2,p3)
2. substr(p1,p2,p3)
3. Length
4. upper
5. lower

- 집계함수는 여러 행의 데이터를 하나의 결과값으로 집계하는 반면, 일반 함수는 한 행의 데이터에 하나의 결과값을 대상으로 한다.<br>
따라서 **집계 함수는 select 에서만 사용 가능 하지만 일반 함수는 select에서도 쓸 수 있고, where 절에서도 쓸 수 있다.**

- 문제
1. products에서 정상 가격을 모두 더한 값
2. products에서 제품 아이디가 30이하인 제품의 정상 가격의 평균
3. users에서 가입일시가 2010-10부터 -12까지인 회원 아이디를 중복 없이 센값
4. users에서 이메일의 길이가 17자리

```sql
SELECT SUM(price) AS '합계'
FROM products;

SELECT round(AVG(price),2) AS '평균'
FROM products
WHERE id <= 30;

SELECT COUNT(DISTINCT username) AS '유저수'
FROM users
WHERE substr(created_at,1,7) BETWEEN '2010-10' AND '2010-12';

SELECT COUNT(DISTINCT username) AS '유저수'
FROM users
WHERE length(username) <= 17;

```

# group by
1. country가 korea인 애
2. country가 usa인 애
합은?
```sql
SELECT COUNT(country)
FROM users
WHERE country = 'korea' or country = 'USA' ;
```

```sql
SELECT country, COUNT(id) -- 뭐로 그루핑했는지에 대한 명시와 ,같은 나라의 id들을 더해주는것
FROM users
WHERE country = 'korea' or country = 'USA' 
GROUP BY country;
```

이상의 쿼리문을 실행했을때 국가별 회원수를 확인 가능

- select 절에만 집꼐 함수를 쓸 수 있다.
- group by를 명시하지 않았을 때는 전체 row를 기준으로 집계 함수가 일어난다.
- group by 컬럼명을 명시하게 될 경우 해당 컬럼의 중복되는 row값들을 다 합치게 된다.

그렇다면 group by까지 포함한 쿼리문의 연산 결과에 대한 전체 row의 개수를 미리 알 수 있을 것이다.

- group by 컬럼명 a를 작성했다면 가시성을 위해 select문에도 컬럼명을 명시해주는 것이 어떤 값에 집계함수 결과가 무엇인지를 명확하게 보여주는 방법이 될 것이다.

```sql
SELECT country,is_marketing_agree AS 동의 , COUNT(id) AS '동의사용자'
FROM users 
GROUP BY country, is_marketing_agree
ORDER BY country , '동의사용자' DESC;
-- 동의 0 , 1마다 몇명씩 있는가
```

- order-by문은 select 까지의 sql문을 재정렬
